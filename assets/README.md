# Recursos propios de Iconos

Esta carpeta debe contener únicamente el icono identificativo `Iconos_App.ico` suministrado con el paquete fuente oficial V0.1.5.

**Pendiente de subir el binario exacto.** No reemplazarlo por una imagen de muestra ni reconstruirlo con un diseño diferente.

Este recurso es necesario para compilar el EXE con el icono oficial y generar el instalador Inno Setup.
