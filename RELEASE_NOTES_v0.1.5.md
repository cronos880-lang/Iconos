# Iconos V0.1.5 — Primera versión oficial

Aplicación independiente para Windows que convierte PNG, JPG y WebP a ICO con representaciones de 16, 24, 32, 48, 64, 128 y 256 píxeles.

- Conversión individual y por lotes.
- Vista previa y ajustes Centrar, Recortar y Estirar.
- Filtros Lanczos y Bicubic y selección automática experimental.
- Transparencia RGBA y archivo ICO con imágenes internas BMP/DIB y PNG.
- Selección del nombre y la ubicación de salida.
- Interfaz con icono propio, botón Salir e inicio maximizado.

Instalador oficial probado por el usuario en Windows: `Iconos_Setup_V0.1.5.exe`.

**SHA-256:** `8c3b70a97c64947e41112bdeb86a3e43d44e62bcea806b06504ad4066d607ead`

El instalador debe adjuntarse a una GitHub Release cuando esté disponible el mecanismo de subida de binarios. No confundir estos archivos de documentación con una Release publicada.

La Suite de Programas B V0.3.3 no ha sido modificada. No se incluyen imágenes ni iconos de muestra.
